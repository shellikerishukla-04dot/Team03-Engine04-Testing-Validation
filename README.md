# Engine 4 – Testing and Validation

## Project
Interior Design and Recommendation System


## Purpose
Tests and verifies the correctness, reliability, and functionality of the Interior Design and Recommendation System.

## Technologies Used
- React.js
- Node.js
- Express.js
- MySQL
- JavaScript

## Implementation
- Test cases for different room types.
- Validation of room dimensions.
- Testing of different interior design styles.
- Testing of colour preferences.
- Budget-based filtering tests.
- Testing of missing and invalid inputs.
- Verification of preference matching.
- Testing of suitability-score calculation.
- Verification of recommendation sorting and ranking.
- Testing of database connectivity and preference submission.

## Testing Categories
- Functional Testing
- Input Validation Testing
- Database Testing
- Recommendation Logic Testing
- User Interface Testing

## Expected Output
Verified input handling, accurate preference matching, correct recommendation ranking, and reliable interface behaviour.
